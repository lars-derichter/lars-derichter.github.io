Deze site is een statische website. Er draait geen database, geen CMS en geen
JavaScript in je browser. Elke pagina is een bestand dat op voorhand gebouwd is.

## De techniek

| Onderdeel | Wat                                              |
| --------- | ------------------------------------------------ |
| Generator | [Eleventy](https://www.11ty.dev) 3, met Nunjucks |
| Hosting   | GitHub Pages, gebouwd door GitHub Actions        |
| Stijl     | Handgeschreven CSS, geen framework               |
| Analytics | Geen                                             |
| Cookies   | Geen                                             |

De broncode staat op
[github.com/lars-derichter/lars-derichter.github.io](https://github.com/lars-derichter/lars-derichter.github.io).

## De vormgeving

Het uiterlijk komt uit mijn eigen
[Slidev-theme](https://github.com/lars-derichter/ldr-slidev-theme), zodat mijn
slides en mijn blog aan elkaar verwant zijn. De uitgangspunten daarvan:
typografie draagt de hiërarchie, geen schaduwen of kleurverlopen, warme
natuurlijke kleuren, en groen als hoofdaccent met rood als spaarzame vonk.

Twee lettertypes doen al het werk.
[Gentium Book Plus](https://software.sil.org/gentium/) voor lopende tekst en
titels, en [IBM Plex Mono](https://www.ibm.com/plex/) voor code.

De slides staan op een perkamentkleurige achtergrond. Deze site niet: voor
teksten die je langer dan één scherm leest is dat te donker en te druk.
Perkament blijft hier voorbehouden aan de kop van de pagina, de intro en
kaderteksten.

## Toegankelijkheid

Ik probeer de site bruikbaar te houden zonder muis en met een screenreader:
echte koppenstructuur, zichtbare focus, een skip-link, en tekstcontrast dat de
WCAG AA-drempel haalt. Werkt er iets niet, laat het me weten.
